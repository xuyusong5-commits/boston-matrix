# 四象限矩阵

给门店、餐厅和工厂用的二维矩阵。横轴、纵轴的名字自己定，把菜品、商品或产线放进去，按平均值分成四格，看哪些该加码、哪些该收缩。

经典波士顿矩阵会把坐标写成份额和增长。这里不锁死指标：点击率、毛利率、复购、坪效、良品率都可以。四格标题会跟着坐标名变化，例如「高点击率 · 高毛利率」。

数据只在这次打开的页面里计算，没有账号，也没有数据库。

## 本地运行

需要 Python 3.10 或更高。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 <http://localhost:8501>。

Windows 上激活虚拟环境用 `.venv\Scripts\activate`。

## 怎么用

1. 在左侧改横轴、纵轴的名字。图、均值和四个格子的标题会一起换。
2. 在品项表里改名称和数值，也可以增删行。
3. 十字线是当前有效行的平均值。高于均值算「高」，低于或正好等于均值算「低」。
4. 「载入示例」会放上一家社区餐厅的菜品，并覆盖当前表格和坐标名。
5. 可以上传 CSV，或把当前表格下载下来。下载的文件带 UTF-8 BOM，Excel 打开中文不会乱码。

### CSV

第一列是名称，后面最先出现的两列数字是坐标。表头会变成坐标名。中间如果夹着文字列，会自动跳过。

```csv
品项,点击率,毛利率
手工柠檬茶,8.6,66
可乐,9.0,22
```

编码用 UTF-8，或 Excel 常见的 GBK。百分号和千分位逗号可以写在数字里，例如 `66%`、`1,200`。

空行会忽略。缺名称或数值的行会留在表里，但不会进图。

## 部署到 Streamlit Community Cloud

1. 把这个仓库推到 GitHub。
2. 打开 [share.streamlit.io](https://share.streamlit.io)，用 GitHub 登录。
3. 新建应用，选中仓库和分支，主文件填 `app.py`。
4. 部署。依赖从根目录的 `requirements.txt` 安装，不需要密钥。

## 本地检查

```bash
python -m unittest test_app.py
```
